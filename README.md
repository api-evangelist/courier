# Courier (courier)

Courier is a multi-channel notification API offering routing across email, SMS, push, chat, and in-app, with templates, preferences, and a no-code studio.

**APIs.json:** [https://raw.githubusercontent.com/api-evangelist/courier/refs/heads/main/apis.yml](https://raw.githubusercontent.com/api-evangelist/courier/refs/heads/main/apis.yml)

### Courier Inbox Real-Time API

WebSocket service that delivers Inbox messages and message-state events (read, unread, opened, archived, clicked, mark-all-read, archive-all, archive-read) to authenticated users in real time.

- **Human URL:** [https://www.courier.com/docs/platform/inbox/inbox-overview](https://www.courier.com/docs/platform/inbox/inbox-overview)
- **Base URL:** `wss://realtime.courier.io`
